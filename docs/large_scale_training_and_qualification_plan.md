# Large 十层资格训练

Large 用于论文规模的 Full-only 版本资格训练。当前保留十层模型、checkpoint、数据映射和生成论文数据所需脚本；版本链、数据冻结和指标定义见 [实验设计](experimental_design.md)。

资格训练只回答候选 Current 是否相对 Parent 的 Full 质量和效率满足准入条件。准入成立后，才可以为该版本边建立缓存兼容性评价；未准入的候选不会改变服务父版本或缓存谱系。

每次新的 Large 训练必须在启动前封存合同、资源估计和 canary，且获得用户明确授权。单次任务最多使用一个四卡 FSDP 作业；训练种子与发布边串行排队。运行日志、退出状态、原始结果和必要哈希与合同一同保存。
