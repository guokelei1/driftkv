# Introduction（前半部分）与 Motivation

## 1 Introduction

### ¶1 领域与重要性

生成式推荐系统（Generative Recommendation）正在重塑推荐系统的技术范式。与传统"召回—排序"两阶段管道不同，生成式推荐将用户历史交互序列直接输入 Transformer 架构，通过自回归方式生成推荐结果，实现了端到端的统一建模 [HSTU, TIGER, P5]。这一范式在工业界已取得显著成效：Meta 的 HSTU 模型在 8,000 亿参数规模下部署后，相较于传统深度推荐模型实现了 12% 的效能提升，驱动了 Facebook Reels、Watch 等核心场景的推荐质量突破 [Internet-Scale GR]。生成式推荐的核心优势在于：统一了推荐管道、消除了特征工程的复杂性，并通过序列建模捕获用户兴趣的动态演化。

### ¶2 现有方法及其合理性

HSTU（Hierarchical Sequential Transduction Units）作为当前生成式推荐的代表性架构，其设计借鉴了大语言模型（LLM）的成功经验。HSTU 采用纯 Transformer Decoder 结构，并引入**点态注意力**（Pointwise Attention）机制——以 $(\text{elu}(\mathbf{Q}\cdot\mathbf{K})+1)\cdot\mathbf{V}$ 替代传统的 Softmax 归一化——实现了对大规模推荐数据的稳定训练。与 LLM 类似，HSTU 在推理时依赖 **KV Cache** 机制：将用户历史交互序列的前向计算中间结果（Key、Value 矩阵）缓存，使新交互仅需增量计算而非全序列重算，将推理复杂度从 $O(L^2)$ 降至 $O(L)$。这一机制使生成式推荐在生产环境中的实时推理成为可能。然而，现有 HSTU 的 KV Cache 研究主要聚焦于**静态模型假设**下的推理加速 [HSTU Serving, vLLM, SGLang]，忽略了推荐系统区别于 LLM 的一个关键特性：**持续流式训练**。

### ¶3 问题与结构性缺陷

**然而**，推荐系统的模型参数在持续演化。与 LLM 以月为单位的训练周期不同，推荐系统通常以天甚至小时为单位进行流式训练（Streaming Training），不断将新用户交互数据融入模型 [Internet-Scale GR, Continuous Training @ Meta]。考虑一个典型的流式训练场景：模型在第 $t$ 个窗口训练完成后产出参数 $\theta_t$，并为 $N$ 个在线用户计算并缓存了 KV Cache $\{F(\theta_t, x_u)\}_{u=1}^{N}$；第 $t+1$ 个窗口，新交互数据到达，模型更新为 $\theta_{t+1} = \theta_t + \Delta\theta$。此时，所有用户的 KV Cache 变为**过时（Stale）**：缓存中的 $F(\theta_t, x_u)$ 与最新模型应产出的 $F(\theta_{t+1}, x_u)$ 之间存在漂移（Drift），其大小为 $\|F(\theta_t, x_u) - F(\theta_{t+1}, x_u)\|$。

这一漂移并非可以忽略的微小扰动。我们在 KuaiRand-1K 数据集上的实验表明（图 1），经过 6 个 3 天窗口的流式训练，模型参数的相对漂移 $\|\Delta\theta\|/\|\theta\|$ 从 6.6% 增长至 47.0%，导致超过 **82%** 用户的 Top-10 推荐列表发生改变。更为关键的是，Stale KV Cache 导致了可量化的推荐质量退化：在参数漂移达到 42% 时，**76%** 用户的正样本排名显著恶化（平均退化 346 个排名位置，Spearman $\rho = -0.701$, $p = 0.0036$）。

问题的根因在于一个**结构性错配**（Structural Mismatch）：KV Cache 的复用以模型参数不变为前提，但推荐系统的流式训练本质上是参数持续变化的。消除 Stale KV 需要为所有 $N$ 个用户重新计算前向传播，其代价为 $O(N)$ 次完整推理——在工业规模下（$N = 10^8$ 用户），这一开销与完整模型推理等价，使得 KV Cache 的加速效果被完全抵消。这构成了生成式推荐系统在流式场景下的一种**固有局限性**：**KV Cache 的复用价值与模型更新频率之间存在根本性矛盾**。

### ¶4 关键洞察

我们的关键洞察是：虽然直接计算每个用户的 KV 漂移 $\|F(\theta_t, x_u) - F(\theta_{t+1}, x_u)\|$ 需要 $O(N)$ 次前向传播，但**这一漂移可以被低成本地估计**。具体而言，我们观察到 Stale KV Cache 导致的推荐质量退化与用户隐藏表示（Hidden Representation）的余弦相似度高度相关：当模型从 $\theta_t$ 更新为 $\theta_{t+1}$ 时，用户 $u$ 在新鲜 KV 与过时 KV 两种条件下的最终隐藏状态 $\mathbf{h}_u^{\text{fresh}}$ 和 $\mathbf{h}_u^{\text{stale}}$ 的余弦相似度 $\cos(\mathbf{h}_u^{\text{fresh}}, \mathbf{h}_u^{\text{stale}})$ 从 1.0 单调下降至 0.58，与参数漂移 $\|\Delta\theta\|/\|\theta\|$ 的 Spearman 相关系数达到 $0.924$（$p < 0.001$）。这一发现意味着：**无需重新计算 KV Cache 即可判断哪些用户的 Cache 已严重过时**——仅需一次低成本的 Hidden State 对比即可完成估计，其代价远低于 $O(N)$ 次完整前向重计算。

## 2 Motivation

本节通过真实数据集上的系统实验，从三个维度论证上述问题的严重性与解决方向的可行性：

1. **流式训练导致的参数漂移规模与推荐结果变化**（§2.1）；
2. **Stale KV Cache 对推荐质量的影响**（§2.2）；
3. **漂移的可检测性——是否存在比完整 KV 重计算更低成本的信号**（§2.3）。

### 2.1 实验设置

**数据集。** 我们使用 KuaiRand-1K 数据集 [KuaiRand]，包含 999 个用户、20,000 个物品和 17 天的流式交互日志（2022年4月22日至5月8日），时间戳精度为毫秒级。该数据集的毫秒级时间戳和连续两周的观察窗口使其非常适合流式训练漂移研究。

**模型。** 我们实现了一个 6 层 HSTU 模型（隐藏维度 256、8 个注意力头、每头 64 维、最大序列长度 512），采用 ReLU 激活函数，共约 18M 参数。模型遵循 HSTU 的点态注意力设计：$(\text{elu}(\mathbf{Q}\cdot\mathbf{K})+1)\cdot\mathbf{V}$，无 Softmax 归一化。

**三角形评估矩阵。** 为系统量化 Stale KV 的影响，我们构建了三角形评估矩阵（图 2）：

- **基础训练**：以 14 天数据（4月8日—4月21日）训练基础模型 $\theta_0$，共 50 个 Epoch。
- **流式训练**：以 3 天为窗口进行 6 轮流式训练，产出 $\theta_1, \ldots, \theta_6$。每轮训练采用经验回放（Experience Replay）策略，以 50% 新数据 + 50% 回放数据混合训练，缓解灾难性遗忘。
- **评估**：模型 $\theta_t$（在第 $t$ 个窗口训练完成）使用 $\theta_0$ 计算的 KV Cache（Stale）与使用自身参数重新计算的 KV Cache（Fresh）进行对比，在全量 20,000 物品目录上对 300 个评估用户进行排序。

这一设计确保了训练数据与评估数据的严格分离：评估窗口 $W_s$ 的数据仅在模型 $\theta_t$（$t < s$）训练完成后才被观测，不存在信息泄漏。

### 2.2 流式训练导致显著的模型漂移

**参数漂移。** 图 3(a) 展示了参数相对漂移 $\|\Delta\theta\|/\|\theta_0\|$ 随流式训练窗口的增长。$\theta_1$（1 个窗口后）的漂移为 6.6%，到 $\theta_6$（6 个窗口后）已达到 **47.0%**。这一漂移规模远超 LLM 场景下的典型模型更新量级（通常 $<5\%$），反映了推荐系统高频流式训练的特性：每日新增的交互数据持续改变模型对用户兴趣的建模。

**推荐结果变化。** 参数漂移直接导致推荐结果的实质性改变。我们以两个指标量化这一变化：

- **Top-10 推荐变化率**：同一用户在 $\theta_t$ 和 $\theta_0$ 下 Top-10 推荐列表的不重叠比例。该指标从 0%（$\theta_0$ vs. $\theta_0$）增长至 **82%**（$\theta_4$ vs. $\theta_0$），表明流式训练实质性地改变了推荐结果。
- **1-Spearman 相关差异**：$1 - \text{Spearman}(\text{score}_{\text{fresh}}, \text{score}_{\text{stale}})$，衡量全量排序的整体变化。该指标从 0 增长至 **0.192**，与参数漂移的 Spearman 相关系数为 $0.928$（$p < 0.001$）。

图 3(b) 展示了这两个指标随参数漂移的单调增长趋势。结果表明：**流式训练不仅仅是模型参数的微调——它实质性地改变了推荐结果**，使得基于旧模型计算的 KV Cache 所生成的推荐已无法反映用户当前的兴趣偏好。

> **[Figure 3]** (a) 参数相对漂移 $\|\Delta\theta\|/\|\theta_0\|$ 随流式训练窗口单调增长，6 个窗口后达到 47.0%。(b) Top-10 推荐变化率（左轴）与 1-Spearman 差异（右轴）随参数漂移单调增长。

### 2.3 Stale KV Cache 导致推荐质量退化

**评估指标。** 我们在 15 个非平凡评估单元（$\Delta\theta > 0$）上对比 Fresh KV 与 Stale KV 在多种指标下的表现，包括 MRR、NDCG@10、Hit@1/10、Best Rank（最佳正样本排名）、Mean Rank（所有正样本的平均排名）以及 Rank Displacement（排名位移）。表 1 汇总了各指标在所有非平凡单元上的均值。

**表 1：Stale KV 质量影响汇总（$\Delta\theta > 0$，15 个评估单元）**

| 指标 | Fresh | Stale | 差异 (F−S) | Stale 更差占比 | Spearman($\Delta\theta$, 差异) |
|:---|:---:|:---:|:---:|:---:|:---:|
| MRR | 0.033 | 0.036 | −0.003 | 51% | 0.227 (p=0.42) |
| NDCG@10 | 0.007 | 0.008 | −0.001 | 5% | 0.002 (p=0.99) |
| Hit@1 | 0.007 | 0.009 | −0.002 | 1% | 0.312 (p=0.26) |
| Hit@10 | 0.065 | 0.072 | −0.007 | 4% | 0.082 (p=0.77) |
| Best Rank | 423 | 424 | −1.1 | 48% | −0.207 (p=0.46) |
| **Mean Rank** | **5,635** | **5,713** | **−78** | **59%** | **−0.701 (p=0.004\*\*)** |
| Top-10 Positives | 0.072 | 0.078 | −0.007 | 4% | −0.015 (p=0.96) |
| Rank Displacement | — | — | 331 | 74% | −0.024 (p=0.93) |

**Top-K 指标的失效。** 传统 Top-K 指标（MRR、NDCG@10、Hit@1/10）无法有效捕捉 Stale KV 的质量影响。由于全量目录包含 20,000 个物品而每个用户仅有 1–3 个正样本，Top-K 指标的绝对值极低（Hit@10 ≈ 7%），Fresh 与 Stale 之间的差异在统计噪声水平之内。Stale 甚至在部分指标上略优于 Fresh（差异为负），这是因为点态注意力中 Query 来自当前模型参数、主导了注意力模式，使得 K/V 的变化对 Top-K 排序影响有限。

**Mean Rank 揭示显著退化。** 与 Top-K 指标不同，**平均排名（Mean Rank）**利用完整的排名位置信息，能够检测到 Top-K 指标无法捕捉的退化。表 1 显示，Fresh 的平均排名比 Stale 低 78 位（5,635 vs. 5,713），且 59% 的用户因 Stale KV 而排名恶化。更重要的是，这一退化与参数漂移显著相关：Spearman($\Delta\theta$, Mean Rank 差异) = $-0.701$，$p = 0.0036$。

图 4(a) 进一步展示了退化随参数漂移的分级趋势：

| 参数漂移 $\|\Delta\theta\|/\|\theta\|$ | Mean Rank 差异 | Stale 更差用户占比 |
|:---:|:---:|:---:|
| 6.6% | −3 | 51%（随机） |
| 16.3% | −50 | 57% |
| 25.5% | −84 | 61% |
| 34.5% | −180 | 68% |
| 42.3% | **−346** | **76%** |

当参数漂移 $< 10\%$ 时，Stale KV 的影响接近随机（约 51% 用户受影响）；但当漂移 $> 30\%$ 时，**68–76%** 的用户因 Stale KV 而排名恶化，平均退化幅度达 180–346 个排名位置。这一阈值效应表明：在合理的流式训练频率下（3 天窗口），仅需 3–4 个窗口即参数漂移达到 30%+ 时，Stale KV 的质量影响即从可忽略变为系统性损害。

**排名位移分析。** Rank Displacement 指标衡量用户最佳正样本在 Stale 排序中相对于 Fresh 排序的排名下降程度。结果显示，平均排名位移为 **331 位**，**74%** 的用户经历了正方向位移（即排名恶化）。值得注意的是，这一指标在所有非零漂移水平下均保持高位（245–424 位），不随 $\Delta\theta$ 显著变化（Spearman $= -0.024$, $p = 0.93$），表明即使较小的模型更新也会导致推荐排序的实质性扰动。

> **[Figure 4]** (a) Mean Rank 差异（Fresh − Stale）随参数漂移变化，负值表示 Stale 更差。拟合线显示单调恶化趋势，阴影区域为 95% 置信区间。(b) 各指标下 Stale 更差用户比例随参数漂移的变化，Mean Rank（红色）在 $\Delta\theta > 0.3$ 时显著超过 50% 基线。

**小结。** Stale KV Cache 导致的推荐质量退化是真实且可量化的。在 3 天窗口的流式训练频率下，参数漂移在 3–4 个窗口后即超过 30%，此时超过三分之二的用户受到负面影响。这一退化无法通过简单忽略来解决——它系统性地损害了推荐质量，且传统 Top-K 指标因稀疏性而无法检测，需要依赖 Mean Rank 等全排序指标才能揭示。

### 2.4 漂移的可检测性：低成本信号的存在

**核心挑战。** 上述发现证明了 Stale KV 需要被修正，但直接检测每个用户的 KV 漂移 $\|F(\theta_t, x_u) - F(\theta_{t+1}, x_u)\|$ 需要为每个用户执行一次完整前向传播，其代价为 $O(N)$ 次推理——与完整 KV 重计算代价相当。因此，关键问题是：**是否存在比完整重计算更低成本的信号来估计 KV 漂移？**

**观察。** 我们分析了多种潜在的低成本信号与参数漂移之间的关系。图 5 展示了用户最终隐藏状态的余弦相似度 $\cos(\mathbf{h}_u^{\text{fresh}}, \mathbf{h}_u^{\text{stale}})$ 随 $\Delta\theta$ 的变化：

| 参数漂移 | Hidden Cosine | 1-Spearman | Top-10 变化率 |
|:---:|:---:|:---:|:---:|
| 0% | 1.000 | 0.000 | 0% |
| 6.6% | 0.874 | 0.031 | 53% |
| 16.3% | 0.759 | 0.068 | 71% |
| 25.5% | 0.701 | 0.104 | 75% |
| 34.5% | 0.633 | 0.174 | 80% |
| 42.3% | 0.634 | 0.192 | 80% |

Hidden Cosine 从 1.0（无漂移）单调下降至 0.58（$\Delta\theta = 0.42$），与参数漂移的 Spearman 相关系数为 $0.924$（$p < 0.001$）。1-Spearman 同样与 $\Delta\theta$ 强相关（$\rho = 0.924$, $p < 0.001$）。

**意义。** 这一结果的意义在于：KV 漂移导致的推荐质量退化可以通过**隐藏状态的余弦相似度**有效估计。虽然精确计算这一相似度仍需一次前向传播，但相较于为每个用户重新计算所有层的 K/V 矩阵（完整 KV 重计算），Hidden State 的对比可以利用已有的推理中间结果，且可通过 Jacobian-Vector Product (JVP) 等自动微分技术进一步降低估计开销。这为设计**自适应的 KV Cache 更新策略**奠定了基础：仅对漂移严重的用户触发重计算，而对漂移可忽略的用户保持 Cache 复用，从而在推荐质量与计算开销之间取得平衡。

> **[Figure 5]** Hidden State 余弦相似度（蓝）、1-Spearman（橙）随参数漂移 $\Delta\theta$ 的变化。两条拟合线均显示强单调趋势，Spearman $\rho > 0.92$，$p < 0.001$。

### 2.5 Motivation 小结

综合以上三组实验，我们得出以下结论：

1. **流式训练必要性**（§2.2）：推荐系统的流式训练导致显著的模型漂移（$\Delta\theta$ 达 47%）和推荐结果变化（Top-10 变化率达 82%），使得 KV Cache 的复用价值随时间快速衰减。

2. **Stale KV 质量退化**（§2.3）：Stale KV Cache 造成可量化的推荐质量退化。Mean Rank 指标显示，在 $\Delta\theta > 30\%$ 时，超过 68% 用户的排名显著恶化（Spearman $\rho = -0.701$, $p = 0.004$）。传统 Top-K 指标因稀疏性无法检测这一退化。

3. **漂移可检测性**（§2.4）：这一退化可以通过 Hidden State 余弦相似度等低成本信号有效估计（$\rho = 0.924$, $p < 0.001$），为设计高效的缓存更新策略奠定了基础。

这些发现共同指向一个核心设计目标：**构建一种能够低成本估计 KV 漂移、并据此自适应决策（复用/迁移/重计算）的 KV Cache 管理框架**。
