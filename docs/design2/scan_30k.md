# 从3万目录到可解释的场景实验

本轮直接回答：困难用户的**真实AUC**是否获益、当前样本是否漏掉真正的自然短历史，以及一次目标构造能否在后续请求继续提供有用观察。用户授权广泛扫描并扩展实验；原证据保留，未读取任何确认输出。

目录共30000UID。原/扩展确认及保留确认合计8488UID只保留目录身份，详细时间扫描覆盖21512UID；排除旧D2用户和已知拟合后，可供新D2开发的UID为18276。过去部分用户可能参与其他模型开发，因此不称独立确认。

标签值与模型输出均未用于扫描/选人。先固定2048名随机自然用户（包括不活跃者）；再在剩余用户中按原short、old_lineage、mixed、rare_activity四类各选至多512名有真实请求的暴露用户，共2034名，其中自然短历史498名，另三类各512。富集组是有请求条件下的场景实验；其占比与费用不能冒充整个人口。每个目标仍按当时的实际结构重新分组，所有用户/事件均保留，组间重叠单列。

主分组、主0.5/辅助0.1和1.0误差尺度、全局AUC均保持。次要场景将原结构特征拆成：旧谱系且发布前14天零写入、写入数超过原校准99%分位、闲置超过原校准99%分位；用于解释旧状态、突发写入和长期闲置，不新增线上规则或按效果调整边界。附用户内AUC（仅同UID/目标有正负样本的窗口等权），报告支持率，仍以原全局AUC为主。

## 冻结的两个方法

**原225方案**：真实读取证据首次触发后构造Current KV；当场差>0.5则安装，否则本目标不再观察。

**复用目标观察**：筛查、C/H/分组/系数/阈值及提交尺度完全相同。若当场不提交，保留已构造的目标KV作为见证；到下一真实请求时才将期间真实事件native追加到该见证，然后用当前请求核对D1与见证轨迹。严重差异才安装同一份KV。首次构造时它是FreshCurrent，此后是从该点native演化的目标轨迹，不能把后续每次比较称为新FreshCurrent教师。

新机制复用已经支付的目标计算，避免“小误差提早花完观察机会”这一既有盲区；每UID/目标仍至多一次完整构造，但会增加见证追加、读取与存储。模型变化使见证失效，提交后取消双轨；未被请求的见证不主动追加。没有风险网络、未来标签、每个场景专属补丁或二次教师重建。

扫描前固定候选，先通过新队列8UID读取/状态canary，以及旧已开放8UID的追加/延迟安装canary，再执行4082UID×两个策略。四GPU、128UID分块，保守估计总40分钟，使用tmux并保留日志/退出状态；无训练。模型和所有参数不依扩展结果调整。

结果将按随机自然、活跃场景富集分别报告：每类/每边AUC和logloss、UID配对区间、主辅助残余、安装后真实写入与下一发布、全部共享准备与实际追加/读取FLOPs。论文按“问题—机制—获得的效果”组织正文，证据范围与未通过项集中说明，不删除不利行或把条件场景收益升级成全人口保证。

入口：`scripts/design2/scan_population.py`、`run_scan.py`、`queue_scan.py`、`scan_reference.py`、`report_scan.py`；原2048用户的特殊组AUC见`results/design2/scan_30k_01/previous_stratum_quality.md`。

## 扩展结果后的一个固定机制对照

自然组M5仍有AUC损失，不能归结为样本不足。新增一次排序分差门控：仅在原本准备安装的时刻，
复用已经构造的Current KV，用合法held-bank16候选及当前请求计算`delta=目标输出−适配输出`。
当`max(delta)−min(delta)>0.5`才安装，否则保留D1。它测量候选之间的最大分差变化，统一偏移不会触发；
没有反馈标签、分数混合、重新拟合或阈值搜索。冻结设置见`configs/design2/scan_margin_gate_01.json`。
额外16候选的两条读取和修正全部计费。此规则是在看过扩展原方案AUC后提出的开发迭代，不能称独立验证。

先通过既有开放8UID canary（47.97s），再完整重放所有原方案曾安装的34UID（62.67s）。
其余UID原轨迹不可能到达新增门控分支，按归纳保持不变，直接复用；全4082UID仍进入评价。
改变批大小造成共同参考输出最大5.96e−7的FP32舍入差，2e−6绝对检查通过且三个共同参考各边AUC完全相同；
未把舍入差说成逐元素相同。状态动作和后续轨迹真实执行，未用删触发请求或改输出合成“改善”。

完整结果、停止/保留决定与主辅助尺度见[本轮结论](../../results/design2/scan_30k_01/analysis/conclusion.md)。
