## 用户提出的核心设计

> 单边迁移表明，已有缓存通常可以通过紧凑读取修正继续服务。然而，修正有效并不意味着一份缓存可以在任意发布和负载下无限续用：实际状态会经历不同的模型与写入过程，适配误差也具有用户状态差异；同时，持续维护近似表示的成本可能超过一次重建。EvoKV因此不把读取修正当作永远开启的路径，而是管理缓存的续用周期。系统根据实际状态记录和有预算的质量核验，估计继续适配的风险与费用，并将有限目标计算用于最值得重建的状态。重建更新真实KV及其后续起点，而不是仅替换一次预测，因此能够同时处理连续来源变化、少见状态失准和短历史下的成本反转。

这是本阶段的研究目标，不是已完成的系统效果。当前证据限定于冻结六层
Medium、seed17的开发实验，已包含实际连续轨迹；正常低干扰与短历史任务质量仍未完整通过。
Design 1 提供如何修正，Design 2 研究何时有依据继续使用、何时值得在预算内重建。
质量依据与计算费用分别判断，不预设统一健康分数或新的风险网络。
