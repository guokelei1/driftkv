# 专家意见：一次固定的长度/目标条件残余尺度校准

2026-09-08用户提供并授权推进；以下保留本轮建议原文。

**这轮结果支持继续研究几何指标，但下一步应从“原始分数排序”转向“用独立残余给分数建立可比较的尺度”。** 条件置换已经说明，几何信息的价值不只是优先选了便宜状态；不过，低分不等于安全、准确检查费用过高这两个问题仍然存在。现在不进入重建调度器，也不做压缩部署。

**下一轮只做一个假设检验：跨长度、跨目标的误差尺度不同，是否掩盖了几何指标的有效信息？** 建议冻结Design 1、H、所有查询和误差定义，仅使用原512名残余校准用户，按“目标版本×粗历史长度区间”建立一个简单的尺度校准：

$$\widehat e=b_g+a_g u.$$

这里 \(u\) 是原几何分数，\(g\) 是所在组；\(b_g\) 表示该组不能由几何分数解释的基础残余，\(a_g\) 将几何分数换算成实际输出误差的尺度。两项用校准组的**面板最大绝对logit残余**确定，并约束非负，不额外训练高维风险网络。加入基础残余项的原因是：原二次型只描述正则目标附近的预测变化，并不包含实际拟合偏差，不能强迫“小几何分数对应零误差”。

必须保留一个匹配对照：**同样分组、只用基础残余 \(b_g\)，不使用几何分数。** 这样才能判断改善来自长度/版本条件，还是几何真正提供了额外信息。分组、稀疏组处理和拟合规则先固定；只根据校准侧独立UID数量合并过小分组，不根据哪里出现严重失败来调整边界。512人内部按UID做交叉校准，之后冻结规则，再评价原1024名开发用户；这仍是开发验证，不称独立确认。

评价重点保持原来的**续用覆盖—严重残余曲线、低分严重假阴性，以及同预算下相对简单对照的增量价值**。主尺度仍为0.5，0.1/1.0完整保留。尤其检查：已知的低分失败，是被合理的基础残余项识别出来，还是仍然被漏掉。**这种校准最多修复组间尺度，不能凭空修复同组内“低分却严重错误”的排序。** 若只是把整组用户都判成高风险，也要展示因此损失了多少续用覆盖。

费用方面，本轮直接复用已有分数和残余，不需要新模型前向，但应继续报告当前准确检测的完整费用；校准本身不会消除26.12%的全量检查成本。**只有校准后的几何明确优于“仅长度/版本背景”，且低分区域更可靠，下一轮才研究低成本近似或分级检查。** 若做不到，就停止这次尺度修正，不继续换分组、调阈值寻找赢家。几何可以保留为“有预算排序信号”的研究结果，但尚不能承担“允许状态继续复用”的核心判断。
