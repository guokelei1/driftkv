# 专家意见：停止原始可信度，复核几何增量与检查费用

来源：用户在第一轮中规模检测后提供，2026-09-08。以下保存本次专家意见正文，
段落与措辞保留；执行设置、结果和仓库判断另记在 review.md，不将建议当作已经成立的结论。

**我的判断是：这一轮应当停止“把原始几何分数直接当成续用可信度”的路线，但保留它在预算排序中的潜在线索。** 关键反证不是AUROC区间宽，而是**低分并不稳定地对应低风险**：最低约10.6%分数区域的严重率反而高于总体；在拥有更多失败样本的0.1误差尺度上，AUROC也只有约0.58。因此，不能把问题全部归因于主尺度只有13名严重失败用户。

这也修正了我此前的预期：**“参数受到拟合目标约束”与“预测接近Exact”之间，确实存在没有被指标覆盖的部分。** 报告已说明，正则也会使分数变小，而分数本身不包含实际拟合残余。UID988060在拟合内仍出现“低分、大误差”，说明不能只靠降低阈值解决，也不能认为统一一下长度尺度就必然解决。当前实验尚不能唯一判定是尺度问题、模型偏差还是信息缺失。

**5%假想重建预算覆盖全部严重状态，是值得保留的正面结果，但下一步应先弄清“究竟是谁起作用”。** 分数除以重建费用后，既使用了几何信息，也改变了长短历史的排序；目前还不能判断几何贡献有多大。建议下一轮只复用已有结果，比较三条预算曲线：原来的“分数/费用”、单纯按重建费用从低到高，以及**在同目标、相近历史长度内打乱几何分数后再除以费用**。同时报告实际选中了多少UID和状态，而不只报预算百分比。若打乱后收益基本保留，就说明几何信息不是主要来源；若原分数稳定更好，才支持继续研究它的增量价值。

这次复核还必须补上检查本身的FLOPs。按当前每查询59,074,596 FLOPs计算，16候选面板仅几何求解就约 **0.945 GFLOPs/状态**，相当于1024事件Exact重建约 **22.5%**，还没有包含准备和其他操作；短历史上的相对费用会更高。因此，“5%重建预算”远不等于“5%总增量计算”，但这里仍按理论FLOPs判断，不用修订后的计时替代算法预算。

**我的下一步建议是：先完成这一次不新增模型前向的“几何增量价值＋完整检查费用”复核，不立即做归一化搜索、输出敏感度、压缩或真实重建系统。** 保持原0.5主尺度和0.1/1.0辅助尺度，不换一个有利尺度作为成功标准。只有确认几何确实提供了长度与费用之外的信息，才值得预先固定一次长度条件尺度校准；否则就结束这个二次型检测方向，转而讨论需要增加什么独立观测。Design 2的“状态续用与重建”框架不受这次失败否定，**被否定的是它的第一个检测实现，而不是整个框架。**
