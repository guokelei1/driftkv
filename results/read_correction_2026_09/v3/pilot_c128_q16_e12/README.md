## 成本

结构与 v1 相同，因此每个请求的推理 FLOPs 与 v1 相同；改变权重不会改变计算量。
基于冻结完整面板的实际历史长度和新校准账本，投影到每边 3,000 用户后，
新增总成本为 Full−Reuse 的 8.47%～10.99%。这是成本投影，尚无该候选的全 3k AUC。
小样本自身实际摊销成本另存在每条 `evaluation/*/*/summary.json` 中，没有替换或隐藏。
按稳态 Reuse（实际追加 + 公共 query 读取）归一化，比例会明显不同；
总计保留三个成本分母。随后确认采用 Full−Reuse 作为分母；
该候选后续设置与完整结果见[本轮记录](../README.md)。
