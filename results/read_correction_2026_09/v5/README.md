# Read correction 第五轮（2026-09-29）

本轮已完成 15 条边、45 个非线性 Q 点。当前 Motivation 选用本轮 Q，
搭配 H-v4 C64/C128/C256，见[当前 90 点结果](../motivation_final/README.md)。
以下保留方法选择过程和全部开发结果。

本轮按授权先开发和小测，再用 tmux 跑全部 15 条边。期望探索区域为
Q 成本约 0–20%、恢复约 20–40%，H 成本约 60–90%、恢复约 50–70% 或更高；这些是
研究目标，不是结果筛选或质量中断阈值。论文不改，Max 正常评测但不用于方法调参。
本轮名称与基础模型的 V5 版本无关。

固定原 3,000 用户面板，开发检查仍用其中固定 hash 的 128 用户和四条边：Medium
V0→V1 / V3→V4、Large V0→V1 / V1→V2。拟合和验证 UID 均独立于评价面板，只使用
发布前真实历史及教师输出，没有反馈标签拟合、未来状态注入或分数混合。

代码分别在 `scripts/read_correction_v5/query_only/`、`history_conditioned/`，测试也按
方法隔离。共享数据和评分复用既有 reader 与滚动快照，执行时未改写旧 v1–v4 封存来源；当前仅保留仍被调用的共享代码及必要源码快照。
显存上限 70%，启动前至少 75% 空闲；四卡各一条边。完整拟合、教师访问和推理都计费。

## Wave 1：已完成的小样本信号

Q 的两个候选均只读 query 与长度，不读取 K/V 特征：`head_phi` 在每头 ELU(q)+1
上做仿射拟合；`cross_phi` 对跨头 concat(q, ELU(q)) 做仿射拟合。ELU(q) 是拟合
特征假设，**不是**原生 ELU(q·k) 注意力的精确分解。校准使用逐层缓存前缀，避免
反复执行全模型；本阶段只有读取目标岭回归，没有旧 Q v2 的最终输出蒸馏。

H 保持 v4 的非线性 token 映射，改为每用户一个真正混合状态：预发布历史中先由
Parent 初始化，再由 Current 真实滚动追加，Teacher 对同一终点完整重算。训练与验证
分别按 UID 哈希均衡分配目标追加量 `[0,256,512,896]`，切换位于完整 timestamp 组边界。

| 候选 / 恢复率 | Medium V0→V1 | Medium V3→V4 | Large V0→V1 | Large V1→V2 |
|---|---:|---:|---:|---:|
| 新 Q head_phi C128 | 22.16% | 94.44% | 8.66% | -165.88% |
| 新 Q cross_phi C128 | 23.85% | 124.47% | 6.42% | 4.60% |
| H mixed C128，全历史 | 75.77% | 66.85% | 72.45% | 46.46% |
| 旧 H v4 C128，全历史 | 95.37% | 90.25% | 75.11% | 47.59% |

Q 完整 3k 成本投影约 1.14–1.36%；H 约 63.60/64.44/80.91/80.71%。这些质量数字
仅来自 128 用户，不能将其与 3k 成本投影拼成正式 population 点。
`development/wave1/` 保留全部四候选评分和控制，`source_snapshots/wave1/` 保留确切来源。

cross_phi 提升集中在一条 Medium 边，还不稳定。均衡混合 H 缓解了旧 token 占比低时
的过度修正，但损害多数旧状态请求的恢复，四条边均未超过纯旧状态拟合的 v4。
读出误差下降不能替代最终 AUC。所有弱结果都保留。

## Wave 2：固定的后续对照

- Q：cross_phi 的 C512 岭回归，与同一次初始化后 8 轮最终输出教师蒸馏对照。
  教师 loss 沿用用户内中心化分数差及用户均值的训练方差归一化目标；独立 16 用户
  选择 epoch，包含 epoch0。只调整 correction，不调整基础模型。
- H：纯 Parent 状态 C256（只增加覆盖用户），以及 C128 的旧状态占比更高的混合
  校准 `[0,0,256,512]`，同时保留先前纯态与均衡混合态作为对照。
- 仍使用相同四条开发边，不按结果更换用户或边。预计 Q C512+蒸馏约 5–6.3% 成本，
  Large H C256 约 84.0–85.8%，待实际账本核验。

结果据实际对照选择；后续完整运行配置在小测完成后固定，见下节。

## Wave 2 结果与全量选择

四条固定边均已完成，所有候选共用相同 128 用户、相同请求。Q 恢复率为：

| 候选 | Medium V0→V1 | Medium V3→V4 | Large V0→V1 | Large V1→V2 |
|---|---:|---:|---:|---:|
| 旧 Q v2 C512 | 37.33% | 62.07% | 28.29% | -15.76% |
| cross_phi C512，仅逐层拟合 | 16.64% | 93.21% | 4.22% | -93.91% |
| cross_phi C512，增加最终输出蒸馏 | 77.82% | 125.38% | 40.42% | 21.40% |
| H pure C256，全历史 | 94.41% | 92.12% | 71.05% | 45.98% |
| H old-heavy C128，全历史 | 77.64% | 74.33% | 72.33% | 50.79% |

Q 蒸馏的验证集选择 epoch 为 3/7/6/4，包含 epoch0 的选择机制没有停留在初值；
折叠后最大 logit 误差不超过 7.16e-7。固定 3k 面板的独立成本投影依次为
5.59/6.04/6.13/5.50%。这些不是 3k 质量结果；超过 100% 表示小样本 AUC 高于 Full。
只增加逐层拟合用户数在四边均未改善，最终输出蒸馏才改善了此处排序结果。
不能用教师 MSE 代替 AUC：例如 M1 原始 train logit MSE 上升，但训练归一化目标、
验证目标与评测 AUC 改善；新 Q 的部分 MSE 仍比旧 v2 大。

H pure C256 的四边平均恢复为 75.89%，旧 pure C128 为 77.08%；old-heavy 为
68.77%，先前 balanced 为 65.38%。pure C256 成本投影为 67.14/68.24/85.63/84.99%，
old-heavy 为 63.42/64.25/80.73/80.58%。混合校准减轻旧 token 占比低的状态过修，
同时损害多数旧状态请求，因此没有选择其替代旧 H。pure C256 同时移动独立验证组，
不能把 epoch 选择差异完全归因于训练人数。

**全量选择：** Q 统一固定 `cross_phi + joint8`，校准预算 128/256/512，独立验证
用户各 16，15 条边全部评价。H 沿用已完成的 v4 pure C128 全量结果，不重复拟合或
评测同一候选；新 H 的所有弱结果继续保留在开发记录。总图同时保留旧 Q、旧低成本
H 和 v4 H，避免把没有整体改善的尝试包装成进步。Max 只做内存与执行正确性检查，
其质量未参与此次配置选择。全部 15 边的实际成本和恢复率见本文完成结果。

数值检查包括 Query 特征岭回归、真实 mixed append 因果/顺序对照、输出单位折叠与
梯度检查，共 7 个聚焦 CPU 测试通过。开发评测 Full/Reuse/identity 控制误差不超过
9.54e-7，最大显存保留约 21.06 GiB，无 OOM。确切来源快照与阶段退出记录均保留。

## 全量结果（2026-09-29 12:47 CST 完成）

15/15 边、每边 3,000 用户、共 401,187 请求全部完成；新增 45 个 Q 测量点。
队列耗时 4,084.15 秒（68 分 4 秒），退出码与自动绘图均为 0。没有 OOM 或 batch
缩减；评测峰值 allocated/reserved 为 18.45/30.17 GiB；Full/Reuse/identity 最大
控制误差分别为 1.20e-6/1.55e-6/1.44e-6。原始每请求评分与分片继续保留。

下表每格为 **五条边等权平均恢复率 / 成本**，都是完整 3k 面板的实测账本，
不是此前小样本质量加成本投影：

| 规模 | Q C128 | Q C256 | Q C512 | 保留的 H v4 C128 |
|---|---:|---:|---:|---:|
| Medium | 76.52% / 1.49% | 86.14% / 2.79% | 87.98% / 5.44% | 77.65% / 63.02% |
| Large | 42.71% / 1.51% | 31.10% / 2.86% | 36.56% / 5.56% | 67.98% / 80.32% |
| Max | -83.37% / 1.45% | -17.20% / 2.73% | -12.57% / 5.28% | 67.21% / 79.33% |

同预算对比旧 Q v2，Medium 平均恢复提升 46.77/52.70/52.85 个百分点，Large 提升
36.23/12.90/16.42 个百分点。C512 在 Medium、Large 的十条边上全部超过旧同预算 Q。

结果支持 Medium/Large 的低成本 Query correction 潜力。不能概括为预算越大越好：
Large C128 平均反而最高，C256 的 V2→V3 为 -22.91%；各规模均有 4/5 条边的三个
预算点不是单调上升。Medium 均值受 V1→V2 约 164–168% 恢复抬高；超过 100% 指 AUC
高于该边 Full，不是截断或错误归一化。较贵 H 在 Large 的平均恢复更高，但 Medium
新 Q 的 C256/C512 平均已超过旧 H，不能声称加入历史在所有场景必然更强。

Max 仍不稳定，未用于调参。其 C128 V0→V1 为 -528.69%，原始 AUC 为 Q .573006 /
Reuse .620082 / Full .628986，是真实下降叠加小分母放大，不能只归因于归一化。
C512 该边仍为 -89.40%，V3→V4 为 -32.22%。所有点都保留在 CSV 和总图。
