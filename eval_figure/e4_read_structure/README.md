# E4：读取机制与码宽度（模拟表）

**正文使用原生 LaTeX 紧凑表，不再插入 E4 图片。** 本目录的 `plot.py` 只生成 3.35 × 1.9 英寸紧凑表预览，方便总览图册查看；它不属于正文六幅主图。

表有两个区块：

1. **四配置门控对照**：Yambda / RecFlow × Large / Max 的常量门控、动态门控三版平均 AUC 增益，单位 pp；正文另列二者差值。
2. **Yambda-Large 三个结构点**：`36 / 6`、`72 / 18`、`72 / 6` 的质量增益、附加读取 FLOPs 和持久码空间。

`constant_gate` 是独立指定的模拟对照，正式实验需独立训练并延续自己的码和增量状态。它不是临时冻结动态门控，也不是 E1 中每版持久改写 K/V 的静态映射；占位值相同不能证明二者等价。Yambda-Large 的动态／常量门控增益为 1.24／1.15 pp，其他配置同样只是模拟。

结构示例采用 H=10、d=32，同 dtype 下每层每行原生 K/V 为 640 标量。宽码 `12+6H=72`、窄码 `6+3H=36`，分别占 11.25% 和 5.625%（表内按两位小数显示）。保存宽度指整行，读取宽度指每头；默认读取共享 3 维加本头 3 维。窄存窄读与宽存窄读的读取宽度相同，故模拟在线读取 FLOPs 相同。RecFlow 的结构仍是预览假设。

“Read +%”以原生读取 FLOPs 为分母，“Code %”以原生 K/V 字节数为分母，均不同于 E1 的完整成本。共享表、工作区和交接旧新表并存另计于 E6 辅助空间表，不能用码张量比例代替总辅助空间。
