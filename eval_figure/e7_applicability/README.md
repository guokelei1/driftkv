## 计算公式

设 `R(N)=aN+bN²` 为一次历史重建，`S(N)=s0+s1N` 为原生评分，`W(N)=w0+w1N` 为原生行为编码。码物化 `P(N)=p0+p1N`、交接反锚 `H(N)=h0+h1N` 都按整段保留历史计费。当前代新增行用零码，因此均匀交错评分的平均旧前缀长度为 `N−B/2`，B 次行为读取的平均旧前缀为 `N−(B−1)/2`；对应附加读取为 `D_Q=d0+d1(N−B/2)`、`D_B=d0+d1(N−(B−1)/2)`。

```text
F_shared = F_init/3 + F_fit + F_teacher + F_source + replicas × M × f_item
C_Rebuild = U × [R(N) + Q × S(N) + B × W(N)]
C_CacheTide = F_shared + U × [P(N) + H(N)
                             + Q × S(N) + B × W(N)
                             + Q × D_Q(N) + B × D_B(N)]
saving (%) = 100 × (1 − C_CacheTide / C_Rebuild)
```

所有系数以 FLOPs 明示存于 `data.json`，由公式精确生成两组切片。它们是人为设定的算术工作模型，**不是从此前的时间数值转换得到**。共有评分和追加同时出现在分子、分母，因此图上“总 FLOPs 节省”不等于 E1 的“附加工作／重建预算”。纯读写密度外推不添加质量样本，也不保证这些区域有同样恢复率。
