## 当前主线与图表分工

正文按 **整体取舍 → 连续使用与长期边界 → 机制与拟合投入 → 执行时间与持久存储 → 工程优化与条件敏感性** 展开。当前为 **七幅图（一幅双栏主结果、六幅单栏）及三张单栏表**（含配置表）。E1—E7 是作者的问题索引，不决定正文图数或排序。

| 问题 | 正文呈现 | 独立职责 |
| --- | --- | --- |
| E1 整体质量—成本 | 双栏2×6：四配置×三发布的前沿图 | 每版绝对AUC与完整预算；同预算档沿自己的整链状态 |
| E3 连续发布 | 四配置2×2、V1—V5；恢复率线＋成本柱共轴 | 固定默认结构的持续收益与费用；顶部图例解释灰色Δ的AUC缺口含义 |
| E3 长续写趋势 | 单栏成本—恢复率轨迹，点标追加量 | 同一阶段的计算与质量直接配对；无阈值引导，原始AUC另存 |
| E4 读取结构 | 两块原生 LaTeX 表 | 常量／动态门控，窄存／宽存与窄读／宽读的取舍 |
| E5 拟合投入 | 两数据集离散质量—费用散点 | 增加拟合人数是否值得；监督路径仅在必要且有实际证据时补作校准诊断 |
| E2 时间与持久存储 | 单栏2×2时间分解图＋四行原生LaTeX存储表 | 时间收全准备、读写、交接及搬运；表列原生K/V总量、新增字节及比例 |
| E6 工程优化（6.6） | 两面板柱图 | 固定方法下Base→+P→+F的累计时间贡献；与完整方法比较分开 |
| E7 计算边界 | 历史长度、候选读取密度两幅切片 | 成本模型何时失去收益；不充当新的质量或线上性能证据 |

## 统计、费用与视觉编码

- E1逐版前沿和E3默认点共用同一模拟AUC及费用账。用户本轮授权重写乐观模拟：CT集中5—20%预算、基线曲线较平且更长。对应E2／E4／E5的共享默认值同步，避免互相矛盾；不是新实测。旧cohort字段不用于当前两图。
- 当前E2在`e2_time_breakdown/`，使用单独声明的完整事件账和模拟时间系数。正式结果必须核对全链时间及互斥阶段之和，不能从旧路径比值或FLOPs换算。旧`e2_time_scale/`只作历史预览输入。
- E6 各路径分别按自己的 Base 时间归一；它解释同一方法内部的优化，与E2的完整时间比较不同。原第四项 Full 无明确新增机制，保留在 JSON 但不展示、不据其声称减半。
- E4 常量门控与 E1 持久静态 K/V 映射是不同对照。E5 三个拟合人数分别独立训练，各模型组各自拟合；不构造误差棒或跨模型迁移证据。
- E1 新增 FLOPs／重建预算、E2 模型人口阈值、E7 总 FLOPs 节省不能互换，都不等同于时间加速。共享准备、来源／教师准备、所有读写与码交接不漏项；持久存储使用简单总量／新增量表，显存不单列。
- E3 右图扣除双方共有原生服务，Rebuild100%横线表示一次重建的新增费用；完整总账另存。候选数为固定配置且全部费用照计，正式按真实事件逐用户汇总；不增加质量标签，不预设蓝线一定交叉。
- CacheTide 蓝、静态映射红、Rebuild 深灰、Reuse 浅灰。配置比较采用 Yambda 蓝、RecFlow 紫；E3四配置各自独立校准，成本柱用浅色斜线、恢复率线用深色圆点；E5 用实心／空心区分 Large／Max、三种形状区分拟合人数。

E1按约7英寸双栏设计，四配置×三发布排成2×6；其余主图约3.35英寸单栏。E3四配置采用2×2，恢复率与附加成本以线／柱共同展示，Gap仅作旁注且在公共图例说明。图内仅保留轴、图例及面板标识，模拟标识放正文 caption，文件名、JSON 和导出元数据同时保留。
