# Selected five-method figures

Each figure contains the selected 6L, 10L and 16L version edges plus a muted-gold mean curve. The mean is computed at common theoretical-FLOPs positions after clipping displayed recovery to [0,100]. Source data are `../three_scale_auc_preview/cost_ledger.json`; the selections are recorded in `selection.json`.

The concise experiment and method description is in [experiment_summary.md](experiment_summary.md).
