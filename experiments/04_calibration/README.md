对应Figure 8(b)。解释局部读取对齐如何转为评分恢复，以及短尾监督是否改善后续追加中的质量。

- 建议比较：固定fit人数、码布局和其他设置，仅局部→联合直接评分→联合含短尾；人数预算探索引用01。
- 待统一：当前正文仍是fit16／64／256 × 有无tail，执行前确定采用哪一版，避免同时铺开两套扫描。
- 输入：代表组的同一初始配置／角色与事件；各分支独立训练并维护自己的后续状态。
- 输出：当前与共同追加检查点的真实反馈质量、完整拟合FLOPs；不以teacher MSE代替任务质量。
- 资源：质量和FLOPs可共享；如报告校准秒数，从固定起始状态单独重放计时。
