# 03 动态读取与码结构

对应Figure 8(a)。区分候选动态门控的作用，以及保存容量和在线读取宽度的取舍。

- 比较：独立训练／写入的动态与常量门控；窄存窄读、宽存窄读、宽存宽读的必要点。均值门控shadow仅作辅助，不能代替独立writer。
- 输入：代表Yambda-Large、相同角色和可比校准预算；必要时Max复核决定性点。
- 前置：当前更新器支持显式H10布局；36/6、72/6、72/18是可用候选，36/18不能强填。
- 输出：质量、读取FLOPs、持久码字节及来源配置；默认点引用01，不重复训练。
- 资源：质量和FLOPs可共享GPU。若补充实测读取时间，按正式计时规则另测。
- 当前：H6有线索，H10匹配分支尚未完成。

配置放 `configs/`，分支结果放 `runs/`；见[总索引](../README.md)。
