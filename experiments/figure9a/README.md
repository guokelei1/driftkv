## 固定协议与参数

使用现有 Large V0–V5 正式端点，实际结构 10 层、宽 320、10 头、历史上限 1024。沿用上一轮冻结角色及全部 75,807 名评测用户；拟合用户是旧 fit 角色的前缀，不把减少拟合后空出的角色并入测试人口。各边独立校准并从共同的旧版原生缓存初始化。发布时在首次历史消费者（查询或行为追加）之前修复一次，随后按当前模型正常因果追加、FIFO 淘汰。

五条边的窗口依次是 `[231,245)`、`[245,259)`、`[259,273)`、`[273,287)`、`[287,301)`。末边只有 13 个完整源数据日及部分 day300，始终标记为 `E14_partial`。反馈请求按 uid/timestamp/raw item 去重并排除冲突标签，与旧代码一致。不依据模型收益挑选用户。

每条边 29 个实际配置，共 145 个方法／边组合：

- Reuse、Rebuild 各 1 个。
- Layer 共 11 个：1／4／7；12／45／78；123／678；1234；123456；12345678。配置文件用 1-based 闭区间，执行时转换成 0-based。
- Tail、Deviation 分别重算 64／128／256／512／768 个历史位置，短历史取 min(N,k)。不是历史百分比；Deviation 使用当前第 1 层 K/V 差异排序，稳定时间顺序破除并列。

## 加速与四卡

`engine.py` 将方法维和用户维合批。当前模型的完整重算同时提供所有从第 1 层开始的 Layer 前缀；Deviation 各档共享一次固定排序，但成本分别按各方法独立执行计入。任意位置重算使用已有 Triton read 内核融合 QK／ELU／因果掩码／AV，与原始 dense 实现逐请求核对。追加和查询采用 CUDA graphs、共享内存池及二次幂形状分桶。短历史按真实长度执行，不填充伪历史。

正式运行时四张 A40 对每条边划分四份互斥 UID；每张卡保持本片所有方法的独立状态。rank0 为该边拟合一次共享映射，其他卡加载同一权重；汇总时校准成本只计一次。GPU0/1 绑定 NUMA0，GPU2/3 绑定 NUMA1。各边独立重新初始化。

指标保留逐边原始 AUC、相对 Reuse 增益、未裁剪恢复率和完整新增 FLOPs。完整 CPU 事件账本包含无反馈用户与最后一个评分之后的维护事件；GPU 只省略不会影响已评分结果的后缀。成本参照实际独立部署方法，离线共享执行不为单个方法虚减 FLOPs。普通读写与旧缓存构造另列；排序比较次数、随机数生成、索引和搬运不是本口径的 FLOPs。

## KV map 训练与 FLOPs

映射按输入坐标标准化，输出预测标准化的教师 K/V 残差，再反标准化并加回 native K/V。每点采用固定 8 个完整 epoch、8192 行 minibatch（最后不足的 batch 按实际行数）、AdamW，lr=0.001、weight_decay=0.0001、betas=(0.9,0.999)、eps=1e-8；backbone 冻结，只更新映射参数。均值／标准差预处理只做一次。训练前后在同一批发布前拟合行记录 MSE，诊断也计费，不据测试结果选 checkpoint。

令 `G=200, D=32`，`M` 是这一档实际发布前历史行数，`W` 是隐藏宽度。乘加算 2 FLOPs，exp／reciprocal／sqrt 各按 1 个算术操作，符合原生账本的解析口径。

- 部署到一行／一个网络：`4DW + 6W + 6D`，包括标准化、两层矩阵、bias、SiLU、反标准化与残差。完整部署成本是该式乘 `G×所有实际触发修复用户的历史行数`，不是每次查询重做。
- 训练一个实际大小为 `B` 的 batch：forward 的两次 GEMM 为 `4GBDW`；backward 的 `dW2、dH、dW1` 三次 GEMM 为 `6GBDW`。输入 K/V 是常量，没有 `dX` GEMM，不能套一个未说明的时间倍数。
- bias／SiLU 的 forward、SiLU 及 bias reduction 的 backward、MSE forward/backward、AdamW 每次参数更新和标量修正另列。每一步、每一个 epoch 和最后一个 partial batch 都计入。统计标准化、初始化及固定诊断另列。
- 完整 numerator 为：源／教师准备 + 统计与初始化 + 全部实际训练前向／反向／loss／优化器 + 拟合诊断 + 全人口部署映射。除以同边一次 Rebuild FLOPs。

`kv_cost.py` 是不接受任何时间输入的纯计算器。`test_kv_map.py` 用真实 autograd 的矩阵调用形状独立核对前向／反向数量，检查 partial batch、非线性学习和独立逐头执行；并非仅重复成本公式。四卡实际训练记录的行数／更新数／参数数与 CPU 预计算逐项一致。

最终做 1000 次配对 UID bootstrap，包含无反馈用户。五条边各自保留，末边不冒称完整 E14。此目录不修改论文 TOML，不编译论文。

## 保存与恢复

每个 worker 每约 30 分钟在完成当前小批次后原子保存一次，只保留当前和上一代两份压缩检查点。内容是完成游标及计算精确 AUC／配对 bootstrap 必需的标量分数、标签、UID。不能用每块 AUC 的平均代替全体 AUC，因此这些标量是恢复时必需的数字；不保存 K/V、hidden、历史轨迹或逐步输出。每条边最终指标成功落盘后删除临时标量数组，只保留小型配置、来源摘要、映射参数、结果及一份短日志。速度测试不保留评分数组。
