# 05 码准备优化

对应Figure 9(a)。固定算法与权重，测量目录级物品投影复用、跨层合批的独立作用。

- 比较：逐行准备→目录复用→加跨层合批；输入、人口、目录覆盖及精度一致。
- 输入：冻结H10权重、真实K/V／物品ID和共享发布参数；建表、投影及搬运各项按口径计入。
- 前置：H10准备参考与优化路径输出核对通过。
- 输出：准备阶段时间及波动、输出误差、调用／逻辑payload和FLOPs；合批减少调用不自动意味着投影FLOPs减少。
- 资源：数值验证可共享；正式时间需要受控GPU及相关搬运资源。
- 当前：H6实现与组件证据在，H10正式测量待完成。

配置放 `configs/`，计时与核对结果放 `runs/`；见[总索引](../README.md)。
