# Section Function Template

Copy this template to build a draft blueprint for each paper section; fill in the function first, then the content, then the sentences.

For a systems paper, instantiate one blueprint per section of the SYS-01 skeleton (Introduction, Background & Motivation, Overview, each Design section, Implementation, each Evaluation RQ subsection, Related Work, Conclusion); the mandatory functions of each section are listed in [guidelines/14-系统论文结构与体裁.md](../guidelines/14-系统论文结构与体裁.md).

## 5. Language slots

- Background sentence: `[Topic] is/has been [fact/significance].`
- Transition sentence: `However/Therefore/Taken together, [relation].`
- Claim sentence: `This study/paper [verb] [object].`
- Evidence sentence: `[Figure/data/reference] shows/indicates [evidence].`
- Qualifying sentence: `Although [limitation], [bounded claim].`
- Speculation sentence: `These results may/might/could [qualified implication].`
