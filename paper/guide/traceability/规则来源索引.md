## 1. Key evidence points for the original book models

| Model | Reusable sentence function sequence in the original book |
|---|---|
| Introduction | importance/background/problem area -> research map -> gap/problem -> present paper |
| Methods | overview/aim/source -> details/sequence/justification/care -> graphics -> comparison -> background -> issues |
| Results | revisit literature/aim/method -> graphic -> key/evaluated/comparative results -> problems -> implications |
| Discussion | achievement/contribution -> reboot -> results/implications -> literature map -> limitations/future -> applications |
| Conclusion | paper/achievement/background/aim/method/results/implications/limitations/applications/contribution/future |
| Abstract | significance/challenge/what paper does -> method/results/implications -> knowledge/contribution/application |
| Title | reader entry -> focus/method/value -> keyword/discoverability -> expectation fulfilled |

## 2. Processed exceptions and strength downgrades

- The original book explicitly states that the gap in the Introduction can be implicit, so the final document marks "explicit gap" as NORMALLY rather than an absolute MUST.
- The original book explicitly states that Methods is a menu, so the final document does not require every article to use all six components.
- The way Results, Discussion and Conclusion are merged varies with journal and research type, so the models are written as components and interfaces, not fixed paragraphs.
- The original book gives average paragraph length, sentence length and abstract word count; these are retained as observed values for calibrating against target articles, not written as hard acceptance lines. See `guidelines/12` §4 for the full length benchmark table.
- "first", "novel", "significant" etc. in a single paper case serve only as language function examples; the final rules require evidence and scope qualification.
- Target journal formatting, ethics, conflict of interest, data sharing etc. are not in the main body of the original book; they are separately marked as external submission requirements and not mixed with the original book rules.
- The high-risk modal traps (must = certainty without evidence, the three meanings of can, can not≠cannot etc.) come from the detailed analysis in Unit 4 §4.5 of the original book and are retained as MUST-check items because they change sentence meaning rather than being merely stylistic.
- The ten possible meanings of -ing structures come from Unit 8 §8.2–8.3 of the original book and are retained as MUST-check items because -ing is one of the most ambiguity-prone structures in science research writing.

## 3. Recheck method

If you later need to verify against the original book line by line, follow this order:

1. First look up the rule number in this index;
2. Consult the original book and search for the listed Unit and section headings (the source
   transcription is not tracked here);
3. Compare the strength, conditions, exceptions and completion criteria of this rule;
4. If the target article shows a different pattern, add it as a conditional variant; do not delete the original rule directly;
5. Record the target journal, article type and applicable conditions of the new variant.
