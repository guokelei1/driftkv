# Design 2 实现目录

geometry.py 实现冻结 Design 1 坐标下的联合特征、加权 Gram、
平均岭目标的 FP64 Cholesky，以及长度/mask还原后的最大head约束分数。
spectral.py 实现固定32方向的二次型余项上下界，计入谱分解/正交误差与标准FP64舍入预算；
只用于保持冻结检测判定，不提供实际模型误差上界。对应谱准备和回放成本由独立脚本记录。
固定32方向候选费用失败，保留证据，不继续扩张。
conditional.py将完整1281维二次型按共享源编码精确收缩为225维状态矩阵，
包含共享逆残差预算、临时矩阵、数值回退区间和显式算术账本。当前16候选面板通过净费用复核；
单候选不省，状态/目标变化必须重新生成矩阵，校准规则与原始质量保持不变。
范围与待补接口见 [设计审查](../../../docs/design2/review.md)。

后续检测统计、质量依据与真实重建的状态操作放在这里，复用现有 adaptation/models
原语；模型模块不依赖实验脚本。具体实验编排留在 scripts/design2，
不复制 Design 1 管线。lifecycle.py新增真实Current KV/摘要替换与native重建锚点，
将发布年龄、重建记录及状态修订分开管理；变化使读取视图失效。已支持最小真实重建闭环，
没有复杂预算排序器。

rebuild.py提供本轮冻结legacy六层HSTU的cache-only Current计算：64行因果分块、最后一层只计算norm/KV。
实验FLOPs辅助函数复用scripts/design账本并收取块内冗余乘加；没有修改基础模型模块。
分块KV与完整Current的canary一致；真实服务已使用，旧共享准备只作同算法的理论重新计费。
